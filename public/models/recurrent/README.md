# Recurrent networks

Small recurrent networks behind DSAverse's Deep Learning Architectures pages,
run in the browser with `lib/ml/recurrent.js`.

| File | Contents |
|---|---|
| `hold.json` | A plain RNN, an LSTM and a GRU, 4 hidden units each, trained on the hold-a-number task, with their training curves and a four-seed study |
| `translate.json` | Two GRU encoder–decoders, 32 hidden units, trained on toy English → French-like translation: one passes only the encoder's final state, one adds attention. Training curves and an evaluation by sentence length |

**Task.** Hold a number (`lib/ml/sequenceTasks.js`): each step brings a random
value in (−1, 1) and a marker bit that flags one of the first three steps.
From step 4 on, the network must report the flagged value at every step while
new values keep arriving. A plain RNN has no way to switch its input off, so
the later values leak into its memory; the LSTM's input and forget gates and
the GRU's update gate let it close the door and hold the value.

**Models.** Input 2 (value, marker), hidden 4, output 1. Parameters: RNN 33,
GRU 89, LSTM 117 (one bias per gate, where PyTorch keeps two). Weights are stored as plain JSON numbers in the layout
`lib/ml/recurrent.js` uses (`W<gate>` [H, H], `U<gate>` [H, I], `b<gate>` [H],
`V` [O, H], `c` [O]), so the browser loads them without conversion.

**How they were made.** Dev-only, in Node, with the same engine the browser
runs:

```bash
node scripts/ml/train_recurrent.mjs hold
```

3,000 Adam steps on batches of 32 (lr 0.02, then 0.006 for the last quarter;
gradients clipped to norm 1), lengths 5–9 for the first quarter and then 5–60,
mean squared error on every reporting step. The LSTM's forget-gate bias
starts at 3 (σ(3) ≈ 0.95), so its cell begins as a nearly perfect store; with
the usual bias of 1 the network still solved the task but held the value by
rewriting it every step rather than by gating.

Each architecture is trained from seeds 1–4. The one shipped is the seed with
the best share within 0.1 of the flagged value at length 80 on a validation
set (sequence seed 7). `seedStudy` records all four on the test set (300
sequences, seed 99) at lengths 10, 30, 80, 160, 500 and 1000, so the page
can say how typical the shipped network is and how far past its training
lengths (up to 60) its memory lasts.

## translate.json

**Task.** Toy translation (`translateExample` in `lib/ml/sequenceTasks.js`):
clauses such as "the big cat sees a dog", joined by "and", into a French-like
target where each adjective follows its noun ("le chat grand voit un chien").
At most one adjective per noun. Source and target share word ids, so the
reordering is the only thing to learn besides the word mapping.

**Models.** `lib/ml/seq2seq.js`: a GRU encoder and a GRU decoder, hidden 32.
`plain` starts the decoder from the encoder's last state and gives it nothing
else (9,744 parameters). `attention` also lets every decoder step take a
softmax-weighted mix of all encoder states (10,256 parameters).

**How they were made.**

```bash
node scripts/ml/train_recurrent.mjs translate
```

Fresh random sentences of 1–3 clauses every batch (batch 16, data seed 1001),
mean cross-entropy per target word with teacher forcing, Adam at lr 0.01 and
0.003 for the last quarter, gradients clipped to norm 1. The plain model trains
20,000 steps and the attention model 4,000. Weights are rounded to 5
significant figures before the evaluation, so the numbers the file reports are
the numbers of the weights it ships.

**Evaluation.** 400 test sentences per clause count (seed 98 + clauses),
greedy decoding:

| Clauses | Plain: words right | Plain: whole sentence right | Attention: words right |
|---|---|---|---|
| 1 | 100% | 400 of 400 | 100% |
| 2 | 66.9% | 0 of 400 | 100% |
| 3 | 43.7% | 0 of 400 | 100% |
