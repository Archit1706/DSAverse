# Tiny GPT

The small language model behind DSAverse's Transformers and Language Models
pages. Every number those pages show comes from running these weights in the
browser with `lib/ml/tinyGpt.js`.

| File | Contents |
|---|---|
| `model.json` | Config, tensor layout (name, shape, byte offset) and training summary |
| `weights.bin` | Every tensor as little-endian float16, in `model.json` order |
| `tokenizer.json` | The 640-token byte-level BPE merges (`lib/ml/bpe.js`) |
| `training-log.json` | Training and validation loss, and sample text at each checkpoint |

**Model.** GPT-2-style decoder: pre-LayerNorm blocks, learned position
embeddings, tanh-GELU, token embedding tied to the output layer. Vocabulary
640, context 64, width 64, 4 heads of 16, 3 layers, feed-forward 256 —
195,136 parameters.

**Data.** 12,000 short stories generated by the seeded grammar in
`lib/ml/stories.js` (seed 2026): simple sentences with names, objects, places
and pronouns that refer back. No outside text was used. Trained for 6,000
steps of batch 32; final validation loss 0.437 (perplexity 1.55).

**How it was made.** Dev-only; the site build never trains anything:

```bash
node scripts/ml/export-corpus.mjs
python scripts/ml/train_tiny_gpt.py
```

`scripts/ml/fixtures/tiny-gpt-reference.json` holds PyTorch logits computed
from the float16-rounded weights; the JS forward pass matches them to 5e-7.
